# Xag website

The website for [Xag](https://github.com/Artificial-IntelligenceAI/Xag-lang),
a programming language built around high performance, helpful error messages,
and Rust-style memory management.

Nothing is built yet. `SITE-BRIEF.md` says what Xag actually is today, which
parts of that are safe to publish, and which would go stale — the site's scope,
stack and deployment are still to be decided.

Official domains: `xag-lang.com`, and `xag-lang.org` **only**.
